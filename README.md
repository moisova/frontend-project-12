## Особенности проекта

- **Обмен сообщениями в реальном времени:** Мгновенная доставка сообщений и обновление каналов через WebSockets (`Socket.io`).
- **Управление состоянием:** Глобальный стор построен на `Redux Toolkit` (слайсы для каналов, сообщений и UI-состояний).
- **Авторизация и безопасность:** Полноценная система регистрации и аутентификации пользователей с использованием JWT-токенов.
- **Валидация и фильтрация:** Проверка форм на стороне клиента (`Formik` + `Yup`) и встроенная фильтрация нецензурных слов (`leo-profanity`).
- **Интернационализация (i18n):** Мультиязычный интерфейс с переключением языков на базе `i18next`.
- **Мониторинг ошибок:** Интеграция с сервисом `Rollbar` для отслеживания ошибок на продакшене.

---

## Стек

- **Frontend:** React 18, Redux Toolkit, React Router DOM
- **Real-time:** Socket.io-client
- **Стилизация:** Bootstrap 5, React-Bootstrap
- **Формы и Валидация:** Formik, Yup
- **Локализация:** i18next
- **Сборка:** Vite / Webpack
- **Мониторинг:** Rollbar
